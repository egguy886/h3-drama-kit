# 10 踩坑清单（按出现频率）

| # | 坑 | 一句话修法 |
|---|---|---|
| 1 | 参考图和文字冲突，模型按图画 | 文字跟图走，或补状态图；asset_locks 锁住 |
| 2 | 开场/全段像静帧、像慢动作 | 开场全景要动；少写 static；打斗每镜一个动作 ≤1.4 s；不写 slow motion |
| 3 | 门/灯/屏幕提前变了 | 参考图画"动作之前"；状态追踪句写清"第几镜之前保持原状" |
| 4 | 同一个人出现两次 | 站位卡只写不动的人和物 |
| 5 | 人物自己加戏（穿过桌子、走到前面） | 长镜头里每个可见人物写静止状态；拆成说话 + 反应 |
| 6 | 站位乱、换边、Nia 站到 Reeve 身边 | 每镜重述 frame-left/right；精确站位加线稿图 |
| 7 | 人物直视镜头 | 写视线落点 |
| 8 | 多说一句 / 少说一句 | 说话句外不写 say/speak；短句配动作；说完的动作放下一镜 |
| 9 | 屏幕乱码、自带字幕 | 屏幕写空白；镜头短；后期 mask 虚化 + 叠字 |
| 10 | 暗场景切点检测误判 → 白花钱重出 | 切点类只标记不重出；阈值 0.18；先用旧片重测阈值 |
| 11 | 剪辑剪掉半句话、话没说完就黑 | assemble 的台词保护（已内置） |
| 12 | 两条字幕叠在一起 | 极短句并进下一条（已内置） |
| 13 | 接力缝重复一秒、首帧僵 | 同场景硬切换景别；接力只作例外 |
| 14 | 服装被画错（对手和主角同色） | 服装颜色拉开；全景写明谁、什么颜色、在哪 |
| 15 | 雾被画成雨 | 天气写全，地面干湿分开写 |
| 16 | 近景脸上黑点（雀斑放大） | 皮肤写 clean, smooth, evenly toned；泥水只写在衣服/腿上 |
| 17 | 生成器漏替换编号（N-/X- 开头） | 已修；build 会查后台编号 |
| 18 | 重跑 lock_dialogue 把设备声台词放回来 | 之后再跑 plans/move_post.py |
| 19 | zsh 里 `--only $ids` 不拆词 | 逐个列出参数 |
| 20 | 网络异常时自动重提 → 重复扣费 | 不自动重提；先 resume 查；可能已扣费的任务记 pending |
| 21 | Whisper 在静音段幻听 | 看 Demucs 人声轨电平，<−60 dB 即幻听；人耳为准 |
| 22 | 交付标准中途换（E01–E30 旧、E31 起新） | 第 1 集就定好 delivery.json |
| 23 | 没配乐 | 开工就写配乐方案 |
| 24 | 同一招用满（每个情绪点都"近景 + 缓推"；每集同一套开场钩子） | 每段推镜 ≤2 次；钩子只在换地点/悬念时用 |
| 25 | RunningHub 第 7 张图静默丢失；音频不附上 | RH 只用 ≤6 张图；上传后 `@` 看选择器项数 |
| 26 | TikTok Drama Center 提示"黑边：边缘连续黑像素>20px 且>5 秒"（《越线》55/60 集被标，画面其实没有黑条） | 电影感暗调把边缘压成近纯黑被误判；成片统一过 `tiktok_edge.py fix`（抬黑位，片尾保持纯黑）；开工就把交付标准里写上"黑位≥TV 36" |
| 27 | TikTok "分发受限：骇人听闻的内容和血腥内容"（4/60 集；受限>10% 集数会拖累整部剧） | 血滴/碎牙/血溅类极特写缩短或换反应镜头；全集带血造型要有"血迹最少"版参考图；写分镜时查平台规则（见 playbook/08 §9） |
| 28 | 段缝处这段有背景声、下一段没有（每段自带的环境声不同） | 提示词声音行全集统一 `QUIET_SOUND`；Demucs 只留人声；后期按场景铺连续环境底（playbook/11） |
| 29 | 被否决的参考图留在 assets/ 里，资产查找器取"文件名最大"的那张 → 用到了废图 | 废图搬到 `_rejected_refs/`（assets/ 之外） |
| 30 | 剧本换装后提示词里还点名没有参考图的有色衣物 → 被画成别的颜色（E01 Seg3 女主穿上绿裙） | 状态/换装用独立 ID 的参考图；没有图的衣物别在文字里点名颜色 |
| 31 | 一采 0.6MP 爆显存 | 保持 0.4MP × 二采 1.5 |
| 32 | `comfy_run.py batch` 的待办在启动时展开，之后才编译的集不会被带上 | 另起一个 batch，或链式脚本等上一批结束再起 |
| 33 | 视频通话（两头）一个画面里切不清谁在说 | 谁说话就拍谁那一头（各自的场景），不拍分屏 |
| 34 | 长台词 >13.5 s 排不进一段 | 在句号处拆成两段台词（措辞一字不改）；超过 3 句的对白场放宽段数 |
| 35 | 库里缺 `voice_cn` 等字段 → compose KeyError | 角色/场景/道具条目补齐 look_en / layout_cn / voice_cn |

| 36 | 拼接时 ffmpeg 报 `Error applying option 'f' to filter 'tremolo'`（环境底配方里 tremolo 频率 <0.1） | ffmpeg tremolo 的 f 下限 0.1；assemble_episode.py 已钳位，并在失败时打印 ffmpeg stderr |
| 37 | 台词开头词丢了 / 结尾被吞，整句相似度还有 0.9，人工看片才发现 | `qc_lib` 单独查开头/结尾 3 词；出片后自动质检，FAIL 自动换种子重出（playbook/12） |
| 38 | 同种子重出得到同一个结果 | 自动重出一律用新随机种子 |
| 39 | 数字写法（"5 000"）和人名听错（Sincere）造成大量假 ⚠，把真问题淹没 | 判分前数字转英文词、近音词并到原文词 |
| 40 | 台词里的 "..." 被模型在停顿处塞进乱码插词，换种子重出也一样（E04 Seg5 / E06 Seg8 / E09 Seg6） | 提示词里 "..." 换成逗号（build_episode pace()），用词不变；质检加"插词"检查；转写用逐词模式，别用普通模式下结论 |
| 41 | 画面里的屏幕/便签/合同/书脊文字是乱码，原本打算后期叠字 | 前期做带文字的道具参考图（props.json `image_text`），分镜引用；精确文字不进 `en`（否定词会触发 build ❌） |
| 42 | 两个出片进程同时跑一张卡，后者"清显存"打断前者 | 提交前先等队列空，再清显存；单卡同一时间只留一个出片进程 |
| 43 | 批量任务的待办在启动时展开，之后编译的集不会被带上 | 链式脚本分批起；`--only E11:1 E13:6` 精确重出指定段 |
