# 00 全流程总览：剧本 → 资产 → 分镜提示词 → 编译自检 → AutoDL 出片 → 看片返工 → 后期交付

来源：《越线 · Crossing the Line》60 集（E01–E60，480 段、约 120 分钟）全程实战 + RunningHub H3 Enhanced 三晚约 150 条对照测试。
证据标记：**【量产】** = AutoDL 正式生产里验证过；**【RH】** = 只在 RunningHub H3 Enhanced 上验证过（AutoDL 上先用 1 段小样确认）；**【经验】** = 看片总结、未做对照。完整证据表见 `09_规则证据表.md`。

## 一、固定规格（可在 project.json 改）
- 画幅：开工前先问（《越线》9:16 竖屏；16:9 / 1:1 也支持）。
- 每段 15 秒（H3 单次生成上限），每集 8 段 ≈ 2 分钟；台词太密时可放宽段数（先问制片人）。
- 英文对白逐字锁定，不改不译；中文潜台词只给人看，绝不进提示词。
- 前期测试 480p，正式 768p；AutoDL 工作流 `minimax_h3_zm_u24`。

## 二、九个阶段（每阶段都有产出和门禁）
| 阶段 | 做什么 | 工具 / 产出 | 门禁 | 细节 |
|---|---|---|---|---|
| S0 立项 | 画幅、语言、段数、平台交付标准、内容尺度 | `new_project.py` → project.json、delivery.json、decisions.md | 画幅和尺度已确认 | 01 |
| S1 剧本审计 + 对白锁定 | 逻辑/连续性审计；逐字锁台词、估时长；设备声挪到后期 | scripts_fixed/；`lock_dialogue.py` → 02_dialogue_lock.json；`plans/move_post.py` | 无未决逻辑冲突 | 01 |
| S2 资产 | 角色/场景/道具拆成 ID、写库条目、出参考图；声线定档 | library/*.json、assets/、voices.json；`asset_gaps.py` | 缺图清零（或明确按 noref 跑） | 02、03 |
| S3 分镜 | 每集一个 plans/eNN.py：镜头、时长、台词位置、站位、段缝 | `plans/eNN.py` → plan_src.json | 自查清单过 | 04 |

| S8 复盘 | 把验证过的规则写回 playbook / 证据表 | `09_规则证据表.md` | — | 09 |

## 三、一集的命令清单（在项目根目录）
```bash
python3 tools/lock_dialogue.py scripts_fixed/E05_xxx.md episodes/E05/02_dialogue_lock.json   # S1
python3 tools/asset_gaps.py E05                                                              # S2：缺图清单 + 生图提示词
python3 plans/e05.py && python3 tools/compose_plan.py E05                                    # S3
python3 tools/build_episode.py episodes/E05 --voices voices.json                             # S4（自动跑 shot_lint）
python3 tools/axis_lint.py E05 && python3 tools/group_lint.py E05                            # S4 补充：越轴、多人站位
python3 tools/h3_run.py check E05                                                            # S5 免费预检
python3 tools/h3_run.py run E05 --seg 1 2 3 4 5 6 7 8 --dry-run                              # S5 免费：只构建请求
python3 tools/h3_batch.py plan E05-E08                                                       # S5 免费：费用与用时
python3 tools/h3_batch.py run E05-E08 --resolution 768p竖 --window 00:00-08:00               # S5 付费（先问）
python3 tools/dialogue_check.py E05-E08                                                      # S6 台词逐字核对
python3 tools/assemble_episode.py E05                                                        # S7 拼整集
```

## 四、时间与费用（《越线》实测，2026-10）
- AutoDL 价格：768p 高峰（08–24 点）¥0.040/秒，**空闲（00–08 点）¥0.030/秒**；480p ¥0.030/¥0.020。15 秒一段 768p 空闲 ≈ ¥0.45。
- 一晚（00:00–08:00）并发 4：约 85 段，约 ¥40；单段云端中位 13 分钟、最长 18 分钟。
- 重出率：E21–E30 56%（质检误判）→ 修阈值后 E31–E40 **7%**；一集 8 段 ≈ ¥4–5。
- 人的时间大头在 S3 分镜和 S6 看片；工具已把能自动查的都查掉。

## 六、六条底线
1. **付费前先问**：报任务数 × 分辨率 × 时长 × 预估费用，等明确同意；网络异常不自动重提（可能已扣费）。
2. **令牌只在 .env**，不打印、不写进任何文件、不发给别人。
3. **台词逐字**；设备里的声音（广播/电话/电视）不进 H3，后期配。
4. **参考图优先于文字**：两者冲突模型听图——改文字，或补一张状态图。
5. **回到最早出错的一层修**：参考图 → 镜头设计 → 提示词 → 单段重出；一次只改一处；同一段 10 次不过就拆镜头、降复杂度。
6. **任何片子在人看过之前都只是"候选"**；自动分只管时间结构和技术，不管表演、台词、人脸。
