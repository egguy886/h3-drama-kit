# 07 看片、质检与返工（S6）

## 1. 自动质检只是筛子
- `h3_run.py review E05 --seg 3` / 批量自动：切点吻合（45 分）、尾段稳定（25）、首帧承接（20）、技术（10），对照图在 `08_review/`。
- **自动分只管时间结构和技术，不管表演、台词、人脸、逻辑**；任何片子在人看过之前都是"候选"。
- 暗场景/闪光（红色警报、闪电、频闪、火花）切点检测不可信，别据此重出【量产】；分数 <40 的段即使没标 ⚠ 也先看。

## 2. 两遍看片
1. **观众遍**：正常速度不暂停，记下第一个劝退点。
2. **质检遍**：逐个切点看——人物脸/服装、道具状态、空间左右、光、声音、人数。
辅助：`python3 tools/episode_sheet.py E05` 每集一张联系表（每镜中点一帧）；`python3 tools/motion_check.py <片子>` 每秒动作量（前 5 秒 <5 基本就是"像慢动作/静帧"）。

## 3. 台词核对
`python3 tools/dialogue_check.py E05-E08`（本机 Whisper）→ `review/台词核对_*.md`。
- Whisper 在静音段会幻听（"Thank you." / "See you next time"）；带数字、引擎声的句子误报多——❌/低分句先人耳确认，必要时 `--model medium` 再听。
- 真少说/多说一句才重出。

## 4. 人数与重复人物（要靠人看）
- 站位卡钉住的人又在镜头里移动 → 同一个人出现两次【量产 E60】；
- 台词镜会抢相邻镜头的帧，旁边镜头里离场/背景人物容易消失；
- 每秒抽帧数人，人数突增突降就是问题（下一部计划做成工具）。

## 5. 问题 → 回到哪一层修
| 现象 | 根因层 | 修法 |
|---|---|---|
| 服装/道具和文字不一样 | 参考图 | 文字跟图走，或补状态图；更新 asset_locks |
| 门已开/灯已亮（剧情还没到） | 参考图状态 | 场景图改"动作之前"的状态，或另出状态图 |
| 开场像静帧、整段偏慢 | 镜头设计 | 开场全景要动、少写 static、打斗每镜一个动作 |
| 打斗像慢动作 | 镜头设计 | 每个打击 0.8–1.4 s 单独一镜；后期可 1.25–1.4× 变速 + 冲击音效 + 2 帧白闪 |
| 人物穿过桌子/自己加戏 | 镜头设计 | 长镜头里每个可见人物写静止状态；别叠缓推；拆成说话 + 反应 |
| 同一个人出现两次 | 站位卡 | 会移动的人移出站位卡 |
| 站位乱、两人换边 | 镜头设计 | 每镜重述 frame-left/right；需要精确时加站位线稿图 |
| 人物直视镜头 | 提示词 | 写视线落点 |
| 多说/少说台词 | 提示词 | 说话句外的 say/speak 删掉；短句配动作填满镜头 |
| 自带乱码字幕/屏幕乱码 | 提示词 + 后期 | 屏幕写空白；后期 mask 虚化 + 叠字 |
| 脸漂、表情怪 | 单次生成 | 单段重出（换 seed） |
| 声音音色跳 | 后期 | voice_fix 统一 |
- **一次只改一处**，版本号加一；同一段 10 次不过就拆镜头、降复杂度，不靠抽卡硬抽。
- 小瑕疵先问：能不能靠剪辑（裁掉 0.5 秒、插一个反应镜、换景别）解决？比重出便宜【经验】。
- 已出片发现问题，改 plans → build → 单段重出（768p 约 ¥0.45）。接力链下游要跟着重出（所以尽量少接力）。

## 6. 记账
每次生成自动写 `episodes/Exx/06_jobs/ledger.jsonl`；`python3 tools/gen_ledger.py ratio episodes/E05/06_jobs/ledger.jsonl` 统计"每个通过片段平均要生成几次"。新写法（trial）在正式生产里直接用，记成/败，成功 ≥3 次失败 ≤1 次就转正，失败 ≥2 次同因就退回【用户定的规则】。
