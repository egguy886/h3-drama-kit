# 05 编译与自检（S4，全部免费）

## 命令
```bash
python3 plans/e05.py                                   # plans → episodes/E05/plan_src.json（pw.seg 会先查：15.0 秒、≤6 镜、台词 ≤13.5 s）
python3 tools/compose_plan.py E05                      # plan_src + library → plan.json（自动编号 Subject/Picture/Audio、说话人 S1/S2、保留分析、人数句、中文总述）
python3 tools/build_episode.py episodes/E05 --voices voices.json   # 校验 + 生成 05_prompts/segNN.bilingual.md + meta；末尾自动跑 shot_lint
python3 tools/axis_lint.py E05                         # 正反打越轴
python3 tools/asset_gaps.py E05                        # 资产/声线是否齐
```
改分镜 → 只改 `plans/e05.py` → 重跑这三步。**不要手改 05_prompts/**（build 会拒绝覆盖手改过的文件，h3_run 上传时也会提示；确需临时改用 `--force` 并把改动移回 plans）。

## build_episode 拦什么（❌ 不写文件）
- 段数、每段 15.0 秒；每句台词装得下（余量 < 0.3 s 报错，> 1.5 s 警告）。
- 每句锁定台词在英文、中文版**各出现且只出现一次**；说话人都在 voices.json。
- 提示词里没有后台编号（C01/S13/P15）、没有中文潜台词。
- `<Picture N>` / `<Audio N>` 与参考清单一一对应。
- **肯定式**：英文 not/no/never/without/nothing/none/cannot、中文"不要/禁止/没有…"一律报错（台词本身除外）。
- 文字锁（asset_locks.json）、状态锁（state_locks）。
- 警告：人物近景没写视线落点、接力段末镜没写停留、双人同景别接缝。

## shot_lint 查什么（❌ 构建失败；⚠ 提示）
❌：禁用写法（推拉变焦、子弹时间、360 环绕、FPV、H3 内甩镜/急推/叠化/淡出、Shake Strongly、双重曝光、故障风）；台词镜头写慢动作；同场景硬切缝没写 seam_motive；同场景全景接全景；尾帧接力没写 relay_reason。
⚠（逐条看，有意保留的可以不改）：
- 多人动作没写先后/站位；一镜两种运镜；运镜太短；连续 4 个平镜头；无效切镜（景别/人物/角度都没变）。
- 推断词（seems / as if / realizes）、带单位距离、his left/right、碰撞/液体、说话句外的 say/speak/lips part、说完后的动作放在说话镜头里。
- 一镜 >2 个情绪词；<3 秒镜头里 A→B 表情转折。
- 开场全景镜头不动 / 全景里没有持续动作；人物"定格/完全静止"；声音段写了 camera。
- **工具包新增（RH 实测）**：段里 ≥60% 镜头写 static；打击动作镜头 >1.6 s；打斗写慢动作；≥3 人对话段没用"静默锁位首秒"。
- 统计：冲击镜头占比（目标 ≥30%，每段 2–3 个）、反应镜点名情绪比例。

## 摄影指导（可选，强烈推荐）
build 通过后，请 Claude 用"摄影指导"视角逐段审：每段 2–3 个冲击镜头（运镜、仰俯、过肩、极特写、前景框、剪影、转焦）、角度表达权力（强者仰拍、弱者俯拍，权力反转时角度跟着反转）、竖屏用上下纵深、脸要大、光要有来源。只给建议，导演决定采纳哪些，改 plans 再 build。

## 读警告的优先级
1. ❌ 全部清零。
2. 开场不动、static 过多、打斗镜头太长 —— 直接影响"像慢动作"，优先改。
3. 视线、站位、多人顺序 —— 影响连贯，改。
4. 冲击镜头比例、反应镜写法 —— 看情况。
