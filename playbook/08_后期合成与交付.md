# 08 后期合成与交付（S7）

顺序：声线统一 → 设备声 → 拼接（含环境声底、接色）→ 字幕铭牌叠字 → 片头片尾 → 响度。`finish_episode.py` 一条龙（拼接之后的部分）。

## 1. 声线统一（推荐，本地免费）
**安装**（一次性）：
```bash
cd tools/voiceconv
git clone https://github.com/Plachtaa/seed-vc.git          # GPL-3.0
python3 -m venv .venv && .venv/bin/pip install -r seed-vc/requirements.txt demucs soundfile librosa
```
（run_vc.py 已处理新版 torchaudio 的保存问题。首次运行会下载模型。）
**用法**：
```bash
tools/voiceconv/.venv/bin/python tools/voice_fix.py anchor E01 --seg 2 --range 0-4.15 --character "Mia" --note "用户确认 Seg2 声线"
python3 tools/pick_anchors.py E02-E10 [--apply]             # 没有基准的角色，自动挑最干净的一句当候选
tools/voiceconv/.venv/bin/python tools/voice_fix_ep.py E05  # 整集：每个说话人按区间变声到基准
```
- 基准取**用户确认过的 H3 原声**（≥6 秒更稳），不是 TTS 样音。
- 自动校验：静音污染（Seed-VC 会在静音里生成声音，门限到 −60 dB）、逐字、电平差 ≤1.5 dB、时长。输出 `*_vc-<角色>.mp4`，拼接时优先用。

## 2. 设备声（广播/电话/电视…）
VoxCPM2 本地（按 VoxCPM 官方说明装进项目的 `.venv-voxcpm/`，模型下载到 `models/VoxCPM2`）：`.venv-voxcpm/bin/python tools/post_voice.py [--only E05-PA1]`；模型路径 project.json `voxcpm_model` 或环境变量 `VOXCPM_MODEL`。输出 `episodes/Exx/08_edit/post_audio/<id>.wav`，拼接时按 place 铺进去。

## 3. 拼接 `assemble_episode.py E05`
- 段间一律**硬切**，不用叠化；每段开头去掉约 0.08 s 起步帧；对白段结尾只留到末词 +1.0 s（最后一镜至少留 2.2 s）。
- **台词保护**：出点不早于最后一个词 +0.18 s；下一段入点前有词时用 J-cut；集尾切黑不早于最后一词 +0.6 s【量产：曾经全剧 16 处剪掉半句话】。
- L-cut：上一段声音多留 0.25 s 压在下一镜；段间音频 120 ms 交叉淡化。
- **分场景连续环境声底**（library/ambience.json，按场景 ID 选配方，−32～−48 dB 只填静默缺口）：把不同生成镜头粘成同一空间【量产：静默缺口 13 处→1 处】。
- **同场景接色**：同场次同灯光的段向组内中位数拉近 70%，超出上限视为有意光变不校。
- 逐段覆盖：`episodes/Exx/edit.json` = `{"drop":[段号], "trim_in":{段号:秒}, "trim_out":{段号:秒}}`。

## 4. 字幕、铭牌、叠字 `subtitle_episode.py`
- 字幕文字一律取台词锁定原文（逐字），只借 Whisper 词级时间；同时导出 .srt。
- 样式（《越线》定稿，可沿用）：圆体粗字黄字黑边；人物铭牌电影衬线、半透明白 + 小号大写身份行；每集铭牌写 `episodes/Exx/titles.json`。
- TikTok 安全区：字幕中心 70% 高度；关键人脸、手部动作、道具特写放安全框内；铭牌优先左侧；叠字落在 8%–76% 高度。
- H3 自己烧进画面的字幕/乱码：`overlays.json` 用 `style: "mask"` 柔边虚化，再叠正确文字。
- 极短单句（"Father."）并进下一条，防止两条字幕重叠【量产】。

## 5. 片头片尾 `bumper_episode.py`
剧名取 project.json `series_title_en`；片尾定稿：黑色暗角 + 白闪 + 硬切黑 + TO BE CONTINUED 卡；切黑前最后一词到黑屏 ≥1 秒。

## 6. 响度与导出 `finish_episode.py E05`
两遍 loudnorm（−14 LUFS、LRA 11）+ 限幅，编码后实测真峰 ≤ −1 dBTP；输出 `episodes/Exx/08_edit/Exx_v1_768p_final.mp4` + 检查图 `review/final_check/Exx.jpg`。

## 7. 配乐（《越线》缺的一块，下一部必须补）
- 开拍前写配乐方案：每集情绪曲线 + 参考曲风；H3 里一律 `non_diegetic_music: N/A`。
- 剪完统一铺乐，对白处 ducking；预留 music 轨。

## 8. 交付前最后一遍
- 正常速度完整看一遍成片（不是看片段）。
- 字幕不挡脸、断句自然；铭牌剧名不被裁；响度达标；片尾话说完才黑。

## 9. 平台审核（TikTok Drama Center）
- **后台标记**：`正片可优化`（技术项，如黑边）不影响发布但影响推荐；`分发受限`（内容违规，如血腥）影响分发，**受限集数 >10% 或有审核失败的单集会影响整部剧发布**。可替换视频或申诉。
- **黑边**（《越线》55/60 集被标）：判定是"边缘连续黑像素 >20px 且连续 >5 秒"。电影感暗调镜头会被误判。
  ```bash
  python3 tools/tiktok_edge.py check E05                       # 量边缘近黑最长秒数（代理指标，≥4 秒就危险）
  python3 tools/tiktok_edge.py fix episodes/E05/08_edit/E05_v1_768p_final.mp4 -o out/E05_tt.mp4   # 黑位抬到 TV 36，片尾前 1 秒淡出，片尾切黑/To Be Continued 保持纯黑
  python3 tools/tiktok_edge.py fix-all episodes -o out/ --pattern "E*/08_edit/E*_v1_768p_final.mp4" -j 4
  ```
  **新剧直接在 finish 之后跑 fix**；已发布的先拿一集在后台"替换"验证标记是否消失。
- **内容规则**（帮助中心 production_best_practices + 画风治理公告）：禁美化跟踪监控/逼到墙角强吻/拘禁/强迫爱上；禁乱伦与伪乱伦浪漫化（含叔侄）；禁逼真血腥和对施暴过程的放大；AIGC 人物禁止性暗示接吻；亲密戏角色必须是成年人。**写分镜前先过一遍。**
- 清晰度建议 1080p 以上（低于 720p 可能影响推荐）：768p 出片后拼接导出 1080×1920。
- **发布表单要求**（drama.tiktok.com/series/draft，2026-10 所见）：封面 3:4（页面又写推荐 1024×1536，那是 2:3，我们做了 1152×1536），≤10MB；视频 MP4、9:16、≥1080p、5MB–4GB、15 秒–20 分钟，字幕单语言、清晰准确；每部最多 300 条；标题 ≤35 字符，简介 ≤1500；"AI 短剧"声明要如实。
- **要不要超分：默认不做，用 Lanczos**。《错撩》小试（6 秒片 2 条）：RTX VSR Ultra 14 秒，FlashVSR tiny 约 220 秒、full 约 335 秒。放大裁切看，三种都比 Lanczos 略清楚，彼此差别很小；压到 2.5 Mbps 模拟平台二次压缩（码率是假设）后差别更小。FlashVSR 60 集约 ¥240–360，比整部剧出片费还高。RTX 纯 GPU 便宜（约 ¥0.15/集），加上传约 ¥0.6–0.8/集。真要做用 `tools/rtx_upscale.py`。没比过动态闪烁。

## 10. 声音全后期（自有 ComfyUI 路线）
生成不带环境声时，`auto_post.py` 已完成：只留人声 → 场景环境底 → 拼接。之后在此基础上加：画内音效（按 `sound_post`）、设备声（post_audio.json）、配乐（§7）。详见 playbook/11。
- **血腥受限的补救（不重出片）**：`tools/blood_mosaic.py`。在指定时间段里对血迹区域打"灰色马赛克"（去色 + 压暗，血不再是红色）。非红光场景用自动识别血色（`mode: auto`，限定在 `roi` 里），**红光场景（红色警报灯）颜色识别会把灯光当成血，要用手工框 `mode: box` + `boxes`**。`snap` 可把窗口吸附到真实切镜点（用提示词推算的镜头时间有 0.2–0.5 秒误差，必要时用 `detect_cuts` 列出切点再手工校准）。先 `preview` 看原图/效果对比，再 `apply`。《越线》E44/47/52/57 的实操见 `_tiktok_fix/blood/plan_*.json`。
- **写分镜时就避开**：血滴/碎牙/伤口的极特写缩短或换反应镜头；全集带血造型准备"血迹最少"版参考图。
